# HUTOJ Username Change

这是一个遵循 Hydro 官方插件结构的 TypeScript 插件。它在“我的 → 账户设置”页面的“头像”和“个人信息”之间加入“修改用户名”，并在后端限制每个用户 30 天只能修改一次。

## 行为

- 创建账号时的默认用户名不计入修改次数，因此第一次修改可以立即进行。
- 每次成功修改后，会在用户文档中记录 `hutojUsernameChangedAt`。
- 冷却期按连续 30 × 24 小时计算。
- 拥有 `PRIV_EDIT_SYSTEM` 的超级管理员修改自己的用户名时不受冷却限制。
- 超级管理员可在“控制面板 → 用户名管理”中通过 Hydro 原生用户选择器选择任意真实用户；该管理操作需要通过 Hydro 原生 sudo 验证且不受冷却限制。
- 超级管理员修改他人用户名后仍会刷新目标用户的修改时间，目标用户作为普通用户时需等待 30 天。
- 插件会直接检查 Hydro 的正式用户与虚拟用户集合，保证用户名在整个数据库中不区分大小写地唯一；正式用户集合的全局唯一索引同时作为并发写入兜底。
- 用户名格式使用 Hydro 5.0.4 原生 `Types.Username` 规则，页面不额外展示格式说明。
- 用户输入时通过 300ms 防抖接口实时检测全库可用性；检测期间不显示中间提示且保持提交按钮禁用，可用时在输入框右侧显示 Hydro 的绿色带圈对勾图标。
- 普通用户只有通过实时校验后才能提交，提交前还需在 Hydro 原生弹窗中确认 30 天限制；正式提交时仍会重新判重，前端检测不作为安全边界。
- 限制在 MongoDB 条件更新中原子执行，并发提交不能绕过冷却期。

## 兼容性

本插件以 HUTOJ 当前运行的 Hydro 5.0.4 为目标版本，并使用该版本公开的插件 API。模板基于 Hydro 5.0.4 的 `home_settings.html`；升级 Hydro 后，应先对照新版模板检查兼容性。

## 本地校验

```bash
npm install
npm run verify
```

## 安装

将整个目录上传到服务器上的独立目录（不要嵌套在另一个插件中），然后按 Hydro 官方方式启用：

```bash
hydrooj addon add /插件目录的绝对路径
pm2 restart hydrooj
```

为了让本插件的 `home_settings.html` 覆盖默认模板，应确保它在 `addon.json` 中位于 `@hydrooj/ui-default` 和 `frontend-hutoj` 之后。

本仓库没有执行上述部署命令，也没有对 HUTOJ 服务器进行任何写入。
